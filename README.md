# WebScopeX

Passive web endpoint inspection for status, headers, redirects, and timing.

## Features
- HTTP status and redirect inspection
- Security header presence checks
- Response timing summaries
- JSON-friendly results

## Safety
WebScopeX performs read-only HTTP inspection. It does not exploit, brute-force, or modify targets.
